# Sistema de Gestión de Citas para Clínicas

## Descripción
Sistema para administrar pacientes, médicos, especialidades y citas médicas, con registro del historial de consultas.

## Objetivo
Facilitar la gestión de citas en una clínica, evitando conflictos de horario y manteniendo un historial organizado de las consultas.

## Herramientas utilizadas
- GitHub y GitHub Projects (organización y control de versiones)
- Java / Spring Boot
- H2
